# Strata-V100：四卡 V100 性能配置与 256K 验证

[English](README.en.md) · [实测结果](BENCHMARKS.md) · [构建与运行](REPRODUCE.md) · [上游 Strata](https://github.com/Niko1221/Strata)

本项目维护 Strata v0.1.45 的一个实验性社区分支：面向 **4×V100 SXM2 16GB、EPYC 7402、约252 GiB RAM、CUDA 12.6**，提供配置、可选 C++ 补丁、启动检查和可复核测量。它基于上游引擎，不是独立重写的推理引擎。

参考配置：Qwen3.8-Flash-Next IQ3_S，256K 上下文、INT8 KV 全显存驻留、64 GiB/16槽 RAM 会话缓存、全部24576专家和8个快速图、每卡300W上限。

| 最终配置测试 | 中位速度 |
|---|---:|
| 130K 新鲜输入预填充 | 4100.6 t/s |
| 240K 新鲜输入预填充 | 4337.1 t/s |
| 短代码解码 | 148.4 t/s |
| 240K背景代码解码，冷/热 | 94.7 / 90.9 t/s |

最后一行来自相同最终配置的筛选阶段，其他行来自最终回归。结果随输入、采样、投机接受率和上下文长度变化；不承诺全任务170.2 t/s。测试方法、样本数和原始统计见 BENCHMARKS.md。

## 本分支新增内容

- `STRATA_PREFILL_LENGTH_CHUNKS=1`：按未缓存段长度选择2048/4096/8192分块；默认关闭，只编入实验性CUDA路径。显式pipe配置优先，检查点恢复保留原分块计划。
- V100也可运行MMQ pointer-table数值测试；原890项比较零失败，GR/GDN parity通过。
- 可移植配置生成器、启动检查、带缓存命中排除和请求关联检查的测试脚本，以及脱敏逐请求数据。
- 系统大页、专家全驻留、现有上游开关与CPU绑定的测量方法和部署说明。

## 使用前了解

当前配置优先保证单请求延迟，模型请求排队；**16个缓存槽不等于16路同时生成**。长输入会增加其他请求等待，预填充中途取消仍可能等当前段结束。输入、思考和输出共同使用256K。

完整KV配置首卡空闲显存约544 MiB；在本机完成了视觉、长文、缓存恢复和持续负载验证，不能直接推广到其他模型、显存或GPU布局。参考机测后系统已用约130 GiB，64 GiB缓存预算按需使用。请先按上游流程生成适合自己模型的配置，再应用本分支profile，不要复制别人的运行目录。

本轮只验证Linux/CUDA12.6/sm70。HIP、SYCL、Windows以及不同卡数未验证。具体边界和负结果见 BENCHMARKS.md。

## 快速入口

1. 按 [REPRODUCE.md](REPRODUCE.md) 构建本分支的V100引擎，并生成本机模型配置。
2. 用 `tools/make_config.py` 从该配置生成新文件；它保留模型/分词器/视觉路径，不覆盖原配置。
3. 选择无活跃请求的窗口启动新配置，运行 `tools/check_startup.py` 检查大页、完整专家、快速图和上下文。
4. 使用 `tools/bench.py` 运行独立、无其他客户端干扰的速度测试。
